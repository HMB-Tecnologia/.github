# Como contribuir

A colaboração nos repositórios da HMB Tecnologia deve respeitar as permissões de acesso, os requisitos de cada projeto e a confidencialidade de informações.

## Fluxo recomendado

1. Identifique a demanda ou issue relacionada.
2. Consulte a documentação e as restrições do repositório.
3. Verifique branches, pull requests e alterações concorrentes.
4. Crie uma branch dedicada, quando aplicável.
5. Implemente uma alteração objetiva e execute as verificações relevantes.
6. Abra um pull request descrevendo testes, riscos e implantação.
7. Aguarde as aprovações e verificações exigidas pelo projeto antes do merge.

## Critérios de revisão

- Correção funcional e clareza do código.
- Segurança, autorização e proteção de dados.
- Compatibilidade de integrações e banco de dados.
- Cobertura de testes adequada ao risco.
- Impacto operacional, observabilidade e possibilidade de recuperação.

Consulte os [Padrões de Engenharia](docs/ENGINEERING.md).

## Confidencialidade

Não compartilhe código privado, credenciais, dados de clientes ou detalhes de infraestrutura em issues públicas.

## Segurança

Para vulnerabilidades, siga [SECURITY.md](SECURITY.md) em vez de abrir uma issue pública.

## Licenciamento

A existência de um repositório público não implica que outros projetos da organização sejam de código aberto. Consulte a licença de cada repositório.
