# Política de Segurança

A HMB Tecnologia incentiva a comunicação responsável de possíveis vulnerabilidades.

## Divulgação privada

**Não abra issues públicas** contendo detalhes de exploração, credenciais, dados pessoais ou informações sensíveis.

Quando disponível, utilize o recurso **Private vulnerability reporting** do GitHub no repositório afetado. Caso contrário, entre em contato com os responsáveis pela organização por um canal já estabelecido para solicitar um meio seguro de envio.

## Informações úteis

- Descrição objetiva da vulnerabilidade e do possível impacto.
- Componente afetado e versão, quando conhecidos.
- Passos seguros de reprodução, sem incluir segredos ou dados de terceiros.
- Forma segura de contato para acompanhamento.

## Limites de pesquisa

Não execute testes disruptivos, extraia dados, altere sistemas ou acesse recursos sem autorização.

## Compromissos

Este documento não estabelece prazo de resposta, programa de recompensas ou autorização irrestrita para testes de segurança. Políticas específicas de cada projeto prevalecem.
